## 2024-10-24 - Expensive operations on draft input re-renders
**Learning:** Found that `Dashboard.tsx` re-computes `allCategories`, `allFolders`, and `sortedNotes` on every single render. Since the `draftContent` (textarea) state lives in `Dashboard`, typing a single character causes the entire application to synchronously iterate, deduplicate, and sort the entire note collection. Additionally, `CommandPalette` redundantly creates a second instance of `NoteSearchEngine` and rebuilds the full-text search index from scratch on every data sync, duplicating an already expensive operation.
**Action:** Always wrap derived list processing (like filtering/sorting) in `useMemo`. Share heavy instances (like search engines) via props instead of re-instantiating them in child components to avoid duplicated work.
